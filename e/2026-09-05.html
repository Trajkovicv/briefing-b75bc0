KI·01 Anthropic Release Notes

Anthropic: ant CLI 1.30.0 bringt „ant apply" für Ressourcen als Code

Anthropic hat in den Claude-Platform-Release-Notes vom 3. September Version 1.30.0 der ant CLI angekündigt. Neu ist der Befehl `ant apply`, der Agents, Environments, Skills, Memory Stores und Deployments aus Dateien im Repository anlegt und aktualisiert: Ressource in einer Datei beschreiben, `ant apply` ausführen, den ausgegebenen Plan bestätigen. Die dabei geschriebene Lockfile `claude-lock.json` soll eingecheckt werden, damit spätere Läufe — lokal oder in CI — dieselben Ressourcen aktualisieren statt neue anzulegen. Zu Preisen oder Modelländerungen steht in der Quelle nichts.

Für dein Briefing-Skript ändert sich nichts: Es geht um das CLI-Werkzeug, nicht um die Modell-API, und `claude-opus-5` in deiner Config bleibt unberührt. Interessant nur, falls du irgendwann Skills oder Agents versioniert verwalten willst.
