KI·01 Anthropic Release Notes

Anthropic veröffentlicht Python-SDK v1.0 mit Breaking Changes

Anthropic hat Version 1.0 des Python-SDK freigegeben. Die HTTP-Schicht wechselt von httpx auf httpx2, einen gepflegten, API-kompatiblen Fork: eigene http_client-, Timeout- und Transport-Objekte müssen aus httpx2 gebaut werden, die DefaultHttpxClient-Helfer bleiben unverändert. Wer auf Tracing- oder Mocking-Bibliotheken setzt, die httpx patchen, soll beim Start httpx2.alias_httpx() aufrufen. v1.0 setzt Python 3.10 oder neuer voraus und entfernt länger als abgekündigt markierte Teile, darunter die alte Text-Completions-API, die Parameter temperature, top_p und top_k an den Messages-Methoden sowie compaction_control im Tool-Runner.

Das betrifft dein Briefing-Skript direkt, falls es das Python-SDK nutzt: Prüfe, ob du temperature, top_p oder top_k an Messages-Aufrufe übergibst — diese Parameter gibt es in v1.0 nicht mehr. Solange du auf einer älteren SDK-Version bleibst, musst du nichts tun.

USA setzen 50-Prozent-Zölle auf kanadische Waren im Wert von 20 Milliarden Dollar in Kraft

Nach dem Scheitern von Verhandlungen in der Nacht auf Samstag traten die US-Zölle von 50 Prozent um 00:01 Uhr EDT in Kraft. Betroffen sind Güter im Wert von rund 20 Milliarden US-Dollar, das entspricht etwa 5 Prozent dessen, was Kanada jährlich in die USA liefert; genannt werden Produkte von Hockeyschlägern bis Zungenspateln. Premierminister Mark Carney wies das Angebot als "unfair" zurück und kündigte Gegenzölle an — nach seiner Formulierung "Dollar für Dollar". Ein hochrangiger Vertreter Washingtons sprach von einer "verpassten Gelegenheit".

Das ist das Delta zur Zollpause von letzter Woche: Die Pause ist vorbei, die Eskalation läuft. Für dein USD-Bein zählt vor allem, ob der Konflikt auf weitere Sektoren übergreift.
