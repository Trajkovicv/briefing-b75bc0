KI·01 Anthropic Release Notes

Anthropic: Compliance API liefert Transkripte lokaler Cowork- und Claude-Code-Sessions

Laut den Claude-Platform-Release-Notes vom 11.08. gibt die Compliance API jetzt Transkripte von Cowork- und Claude-Code-Sessions zurück, die auf den Rechnern der Nutzer laufen — als Beta für Claude-Enterprise-Organisationen. Dafür gibt es drei neue Endpunkte: eine Liste lokaler Sessions, Metadaten zu einer einzelnen Session und deren Transkript. Genutzt wird der bestehende Compliance Access Key mit dem Scope read:compliance_user_data. Zusätzlich liefert die Claude API nun einen Response-Header anthropic-workspace-id.

Für dich als Einzelnutzer der API ohne Enterprise-Organisation ändert sich nichts; die Compliance-Endpunkte betreffen dich nicht. Der neue Response-Header ist additiv, dein Briefing-Skript braucht keine Anpassung.
